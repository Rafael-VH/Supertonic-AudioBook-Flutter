# Internationalization (i18n)

Multi-language support with ARB files for Spanish and English.

## Overview

| Property | Value |
|----------|-------|
| Source files | `app_es.arb`, `app_en.arb` |
| Template | `app_en.arb` |
| Generation | `flutter gen-l10n` |
| Languages | Spanish (`es`), English (`en`) |
| Packages | `flutter_localizations` + `intl` |

## Setup

### `l10n.yaml`

```yaml
arb-dir: lib/presentation/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
```

### App Setup (`app.dart`)

```dart
MaterialApp.router(
  locale: Locale(ajustes.idioma),
  supportedLocales: const [Locale('es'), Locale('en')],
  localizationsDelegates: const [
    AppLocalizations.delegate,
    GlobalMaterialLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
  ],
)
```

## ARB Key Structure

Keys use **snake_case** with a screen/section prefix:

```
ventana_titulo           # Global
nav_home                 # Dashboard navigation
home_editor_metadata     # Home hub
modelo_titulo            # Model
biblioteca_titulo        # Library
onboarding_paso1_titulo  # Onboarding
log_inicio               # Processing logs
snackbar_procesado       # Snackbar messages
benchmark_titulo         # Benchmark
audio_manager_title      # Audio Manager
```

### Simple Strings

```json
{
  "ventana_titulo": "Supertonic-AudioBook",
  "ajustes": "Settings",
  "cerrar": "Close"
}
```

### Parameterized Strings

```json
{
  "estado_archivo": "File {i} of {n}: {nombre}",
  "@estado_archivo": {
    "placeholders": {
      "i": { "type": "int" },
      "n": { "type": "int" },
      "nombre": { "type": "String" }
    }
  }
}
```

Usage in Dart:

```dart
t.estado_archivo(1, 5, 'archivo.md')
// → "File 1 of 5: archivo.md"
```

## Accessing from Code

```dart
final t = AppLocalizations.of(context)!;
Text(t.ventana_titulo);
```

With fallback (outside localization context):

```dart
final titulo = AppLocalizations.of(context)?.ventana_titulo ?? 'Supertonic-AudioBook';
```

Controllers receive `AppLocalizations` as a parameter (e.g. `HomeController.procesar(t)`).

## Adding New Strings

1. Add the key to **both** ARB files:

```json
// app_es.arb
"nueva_clave": "Texto en español"

// app_en.arb
"nueva_clave": "Text in English"
```

2. Regenerate: `flutter gen-l10n`
3. Use in code: `Text(t.nueva_clave)`
4. Verify: `flutter analyze lib`

## Generated Files

```
lib/presentation/l10n/
├── app_en.arb                    # Edit ✅ (template)
├── app_es.arb                    # Edit ✅
├── app_localizations.dart        # DO NOT edit
├── app_localizations_es.dart     # DO NOT edit
└── app_localizations_en.dart     # DO NOT edit
```

## Rules

1. **Never edit generated `.dart` files** — `gen-l10n` overwrites them
2. **Always edit both ARB files** — keep translations in sync
3. **Use parameterized strings** for dynamic content
4. **Test with both locales** — verify layout with longer translations
