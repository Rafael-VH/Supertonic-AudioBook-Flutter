# Internationalization (i18n)

Flutter localization with ARB files, supporting Spanish and English.

## Overview

| Property | Value |
|----------|-------|
| Source files | `app_es.arb`, `app_en.arb` |
| Generated | `flutter gen-l10n` |
| Languages | Spanish (es), English (en) |
| Package | `flutter_localizations` + `intl` |

## Setup

### Configuration (`l10n.yaml`)

```yaml
arb-dir: lib/presentation/l10n
template-arb-file: app_es.arb
output-localization-file: app_localizations.dart
```

### App Setup (`app.dart`)

```dart
MaterialApp.router(
  locale: Locale(ajustes.idioma),
  supportedLocales: const [Locale('es'), Locale('en')],
  localizationsDelegates: const [
    AppLocalizations.delegate,
    GlobalMaterialLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
  ],
)
```

## ARB File Structure

### Simple Strings

```json
{
  "ventana_titulo": "Supertonic-AudioBook",
  "ajustes": "Ajustes",
  "cerrar": "Cerrar"
}
```

### Parameterized Strings

```json
{
  "estado_archivo": "Archivo {i} de {n}: {nombre}",
  "@estado_archivo": {
    "placeholders": {
      "i": { "type": "int" },
      "n": { "type": "int" },
      "nombre": { "type": "String" }
    }
  }
}
```

Usage in Dart:

```dart
t.estado_archivo(1, 5, 'archivo.md')
// → "Archivo 1 de 5: archivo.md"
```

### Descriptions

```json
{
  "log_muestra": "Generando muestra de voz {voz} ({lang})...",
  "@log_muestra": {
    "description": "Log al generar la muestra de voz para Escuchar.",
    "placeholders": {
      "voz": { "type": "String" },
      "lang": { "type": "String" }
    }
  }
}
```

## Usage in Code

### Accessing Translations

```dart
class ConvertScreen extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final t = AppLocalizations.of(context)!;
    
    return Text(t.btn_procesar);  // "Procesar" or "Process"
  }
}
```

### Parameterized Strings

```dart
t.estado_archivo(1, 5, 'archivo.md')
t.log_config_voz('M1', 5, '1.10x')
t.snackbar_procesado(3, '45 s')
```

### Fallback

```dart
final titulo = AppLocalizations.of(context)?.ventana_titulo ?? 'Supertonic-AudioBook';
```

## Naming Convention

ARB keys use snake_case with screen/section prefix:

```
ventana_titulo           # Global
ajustes_tema             # Settings
home_carpeta_origen      # Home
modelo_titulo            # Model
biblioteca_titulo        # Library
onboarding_paso1_titulo  # Onboarding
log_inicio               # Processing logs
snackbar_procesado       # Snackbar messages
```

## Adding New Strings

### Step 1: Add to ARB files

```json
// app_es.arb
"nueva_clave": "Texto en español"

// app_en.arb  
"nueva_clave": "Text in English"
```

### Step 2: Regenerate

```bash
flutter gen-l10n
```

### Step 3: Use in code

```dart
final t = AppLocalizations.of(context)!;
Text(t.nueva_clave)
```

## Rules

1. **Never edit generated `.dart` files** — they're overwritten by `gen-l10n`
2. **Always edit both ARB files** — keep translations in sync
3. **Use parameterized strings** for dynamic content
4. **Add descriptions** for complex placeholders
5. **Test with both locales** — verify layout with longer translations

## Testing i18n

```dart
testWidgets('shows Spanish text by default', (tester) async {
  await tester.pumpWidget(
    const MaterialApp(
      locale: Locale('es'),
      localizationsDelegates: [AppLocalizations.delegate],
      home: ConvertScreen(),
    ),
  );
  expect(find.text('Procesar'), findsOneWidget);
});

testWidgets('shows English text when locale is en', (tester) async {
  await tester.pumpWidget(
    const MaterialApp(
      locale: Locale('en'),
      localizationsDelegates: [AppLocalizations.delegate],
      home: ConvertScreen(),
    ),
  );
  expect(find.text('Process'), findsOneWidget);
});
```
