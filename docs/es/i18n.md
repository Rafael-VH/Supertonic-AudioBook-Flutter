# Internacionalización (i18n)

Soporte multiidioma con ARB files para español e inglés.

## Resumen

| Propiedad | Valor |
|----------|-------|
| Archivos fuente | `app_es.arb`, `app_en.arb` |
| Template | `app_en.arb` |
| Generación | `flutter gen-l10n` |
| Idiomas | Español (`es`), English (`en`) |
| Paquetes | `flutter_localizations` + `intl` |

## Configuración

### `l10n.yaml`

```yaml
arb-dir: lib/presentation/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
```

### App Setup (`app.dart`)

```dart
MaterialApp.router(
  locale: Locale(ajustes.idioma),
  supportedLocales: const [Locale('es'), Locale('en')],
  localizationsDelegates: const [
    AppLocalizations.delegate,
    GlobalMaterialLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
  ],
)
```

## Estructura de Claves ARB

Las claves usan **snake_case** con prefijo de pantalla/sección:

```
ventana_titulo           # Global
nav_home                 # Navegación del dashboard
home_editor_metadata     # Hub Home
modelo_titulo            # Modelo
biblioteca_titulo        # Biblioteca
onboarding_paso1_titulo  # Onboarding
log_inicio               # Logs de procesamiento
snackbar_procesado       # Mensajes de snackbar
benchmark_titulo         # Benchmark
audio_manager_title      # Audio Manager
```

### Strings Simples

```json
{
  "ventana_titulo": "Supertonic-AudioBook",
  "ajustes": "Ajustes",
  "cerrar": "Cerrar"
}
```

### Strings Parametrizados

```json
{
  "estado_archivo": "Archivo {i} de {n}: {nombre}",
  "@estado_archivo": {
    "placeholders": {
      "i": { "type": "int" },
      "n": { "type": "int" },
      "nombre": { "type": "String" }
    }
  }
}
```

Uso en Dart:

```dart
t.estado_archivo(1, 5, 'archivo.md')
// → "Archivo 1 de 5: archivo.md"
```

## Acceso desde Código

```dart
final t = AppLocalizations.of(context)!;
Text(t.ventana_titulo);
```

Con fallback (fuera de contexto de localización):

```dart
final titulo = AppLocalizations.of(context)?.ventana_titulo ?? 'Supertonic-AudioBook';
```

Los controllers reciben `AppLocalizations` por parámetro (ej. `HomeController.procesar(t)`).

## Agregar Nuevos Strings

1. Agregar la clave a **ambos** archivos ARB:

```json
// app_es.arb
"nueva_clave": "Texto en español"

// app_en.arb
"nueva_clave": "Text in English"
```

2. Regenerar: `flutter gen-l10n`
3. Usar en código: `Text(t.nueva_clave)`
4. Verificar: `flutter analyze lib`

## Archivos Generados

```
lib/presentation/l10n/
├── app_en.arb                    # Editar ✅ (template)
├── app_es.arb                    # Editar ✅
├── app_localizations.dart        # NO editar
├── app_localizations_es.dart     # NO editar
└── app_localizations_en.dart     # NO editar
```

## Reglas

1. **Nunca editar los `.dart` generados** — `gen-l10n` los sobrescribe
2. **Siempre editar ambos ARB** — mantener traducciones sincronizadas
3. **Usar strings parametrizados** para contenido dinámico
4. **Probar con ambos locales** — verificar layout con traducciones más largas
