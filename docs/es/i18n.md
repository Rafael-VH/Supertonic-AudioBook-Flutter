# Internacionalización (i18n)

Soporte multiidioma con ARB files para español e inglés.

## Archivos ARB

| Archivo | Idioma | Ubicación |
|---------|--------|-----------|
| `app_en.arb` | Inglés | `lib/l10n/app_en.arb` |
| `app_es.arb` | Español | `lib/l10n/app_es.arb` |

## Generación

```bash
flutter gen-l10n
```

**NUNCA** editar archivos `.dart` generados en `lib/l10n/`.

## Convenciones de Nombre

| Patrón | Ejemplo | Descripción |
|--------|---------|-------------|
| `app.title` | `App.title` | Nombre de la app |
| `home.selectFolder` | `home.selectFolder` | Acción de pantalla |
| `settings.darkMode` | `settings.darkMode` | Label de ajuste |
| `error.generic` | `error.generic` | Mensaje de error |

### Reglas

- `camelCase` para keys ARB
- Prefijo de pantalla (`home.`, `settings.`, `biblioteca.`)
- Subfijo de tipo (`error.`, `success.`, `label.`, `tooltip.`)

## Acceso desde Código

### En Dart (Widgets)

```dart
Text(AppLocalizations.of(context)!.homeTitle)
```

### En Controllers

Los controllers reciben `AppLocalizations` por constructor o parámetro.

## Parámetros

### Variables Requeridas

```json
{
  "homeProcessingProgress": "{current} de {total} procesados"
}
```

```dart
AppLocalizations.of(context)!.homeProcessingProgress(current, total)
```

### Parámetros con Predeterminado

```json
{
  "errorFileNotFound": "No se encontró el archivo {fileName}"
}
```

## Idiomas Soportados

| Idioma | Código | Estado |
|--------|--------|--------|
| Español | `es` | Completo |
| English | `en` | Completo |

## Agregar Nuevo Idioma

1. Crear `lib/l10n/app_{code}.arb` con todas las traducciones
2. Ejecutar `flutter gen-l10n`
3. Agregar el código al `supportedLocales` en `l10n.yaml`
4. Agregar la opción de idioma en `settings_screen.dart`
5. Tests: verificar que todas las keys existen

## Actualizar Traducciones

1. Editar `app_es.arb` y/o `app_en.arb`
2. Ejecutar `flutter gen-l10n`
3. Verificar que compila: `flutter analyze lib`
4. Commitear ambos archivos ARB + archivos generados

## Tests

Los tests de i18n verifican:

1. Todas las keys en ARB son válidas
2. Todos los placeholders tienen tipos correctos
3. Las traducciones no tienen strings vacíos
4. Los archivos generados compilan correctamente
